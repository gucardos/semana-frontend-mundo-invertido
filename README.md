# 🌀 Mundo Invertido

Projeto Front-End desenvolvido do zero como prática de desenvolvimento web,
tendo como referência o projeto Mundo Invertido apresentado pela Digital
Innovation One (DIO) durante a Semana Front-End.

## 🎯 Sobre o projeto

Este projeto será desenvolvido utilizando HTML, CSS e JavaScript, com o
objetivo de praticar conceitos de desenvolvimento Front-End, responsividade,
interatividade e organização de projetos.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
